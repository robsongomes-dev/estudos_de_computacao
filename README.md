# Estudos de Computação

## Sobre

Repositório que reúne meus estudos de computação. Cada área fica em sua própria pasta, com exercícios, anotações e projetos. O objetivo é praticar, registrar o que aprendo e acompanhar minha evolução.

## Áreas de estudo

| Área | Pasta | Status |
|------|-------|--------|
| Python | [`python/`](./python) | Em andamento |
| Git e GitHub | `git/` | Planejado |
| SQL e bancos de dados | `sql/` | Planejado |
| Algoritmos e estruturas de dados | `algoritmos/` | Planejado |
| Redes | `redes/` | Planejado |
| Linux e terminal | `linux/` | Planejado |

> Substitua ou remova as áreas conforme seu plano de estudos. Quando uma pasta for criada, transforme o nome dela em link, como foi feito em Python.

## Estrutura do repositório

```
.
├── python/          # estudos de Python (com README próprio e checklist)
├── ...              # novas áreas entram aqui, uma pasta por área
├── .gitignore
└── README.md
```

Cada área tem um README próprio, com o checklist de progresso daquele tema.

## Convenções

- Uma pasta por área de estudo, com nome em minúsculas e sem acentos
- README dentro de cada pasta, com objetivo e checklist
- Commits curtos e descritivos, por exemplo: `Adiciona exercícios de listas em Python`
